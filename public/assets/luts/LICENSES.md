# KFL professional LUT presets

These `.cube` files are real Rec.709 LUT assets from the OpenShot project’s curated color collection. OpenShot’s LUT authors file identifies the listed FreshLUTs contributions as CC0; the LUTs may be used and adapted without attribution. We retain source attribution here for transparency.
